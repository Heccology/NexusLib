# Nexuslib version 1.2.0

## Fixes


## Changes
- Errors that occur when adding items to existing creative tabs will no longer crash the game, instead warning the client and skipping the entry

## New Features
- Added `NLSituationalMusicRegistry`
  - Allows for overriding ambient music that should play in certain game scenarios
  - Provides the music manager, level, player, and current biome the player is in
- Added `NLItemUtility`
  - Item components added to the `HAND_ANIMATION_IGNORED_COMPONENTS` list will not be considered when the item switching hand animation is being played
- Added `NLSelectedItemNametagRegistry`
  - Allows for custom item nametags to appear when an item is hovered over
  - Provides the item stack and the original text component
